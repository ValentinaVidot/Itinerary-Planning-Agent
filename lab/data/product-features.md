# SignalDesk: current product capabilities

SYNTHETIC CLASSROOM DATA — fixture v1, 2026-09-17.

SignalDesk combines feedback into a shared workspace. Users can upload UTF-8 CSV
files, label feedback manually, and ask for suggested themes. Every theme links
back to the original imported row so another person can check the evidence.
A weekly Markdown summary can be exported for discussion. A reviewer must approve
suggested labels before the team treats them as final.

The current pilot supports English text. Users may invite up to five teammates;
all teammates have the same workspace permissions. Individual comment threads
are supported. There is no native CRM, email, or messaging integration. Staff
must prepare and upload a CSV; the uploader expects fixed column names and has
only terse error messages. There is no guided import preview or self-service
onboarding checklist. The company estimates that its own support staff need
about two hours to set up each new pilot customer.

The product does not forecast revenue, provide legal advice, or automatically
send messages to customers. It has no multilingual evaluation results. Avoid
claiming these as capabilities or promising that they will arrive before the
pilot. Fine-grained roles and automated audit exports are not implemented.

A useful analysis should explain whether traceable themes and weekly summaries
solve enough of the target segment's problem despite the manual import burden.
